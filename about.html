How This Project Connects to SDG 1

A quick look at the goal this project is built around, and how each tool on this site maps back to it.

What is SDG 1?

SDG 1 is the first of the United Nations' 17 Sustainable Development Goals. It commits every country to ending poverty in all its forms, everywhere, by 2030 — not just extreme poverty, but the lack of income, services, and security that keeps people vulnerable.

Target 1

Poverty Line Check → measuring extreme poverty

Target 1.1 defines extreme poverty using a single, comparable line: currently $2.15 a day. The Poverty Line Check tool uses this exact benchmark, so instead of reading the number in a report, you can compare it against a real income and see immediately which side of the line it falls on.

Target 1

Budget Calculator → resilience to shocks

Target 1.5 is about reducing how exposed poor households are to sudden shocks — a medical bill, a repair, a bad month. The Budget Calculator makes that idea concrete: allocate a modest income across rent, food, transport and healthcare, and see how little room is often left over before a single unplanned expense would tip the balance into debt.

Target 3

This project itself → awareness as a first step

Target 1.b calls for policies and investment that are grounded in a real understanding of poverty. Policy support starts with public understanding. A short, interactive project like this can't end poverty on its own, but by turning a statistic into something you can actually feel — a budget that doesn't quite stretch far enough — it aims to make the problem harder to look away from.

Why this matters

Nearly 850 million people live below the extreme poverty line today. Most of us will never experience that directly, which makes it easy to treat as an abstract number rather than a daily reality for real households.

This project doesn't solve poverty. What it can do is make the trade-offs a little more real for whoever uses it — and a little more understanding, multiplied across enough people, is part of how support for real solutions builds in the first place.
